# Cube Lens · 魔方拍照求解

当前版本 **1.9.0**：在本机浏览器上传二阶或三阶魔方的六面照片，校正颜色，再生成复原公式。

- [下载最新发布包](https://github.com/harrislion813-pixel/Rubic-Photo-solve/releases/tag/v1.9.0)：普通用户选 **HtmFull**；需要 QTM 时选附带完整 HTM 资产的 **QtmStrong** 实验包。
- [完整使用说明](魔方拍照解/README.md)：便携包启动、QTM 完整强表入口、源码运行、复用同版本加速资产与拍摄朝向。

便携包已包含 Python、OpenCV、通用 x64 原生引擎和完整运行表。源码用户下载 `source.zip` 后，可以直接导入同版本便携包的引擎与资产，获得相同配置，无需重新生成大表。

QTM 整体提速目标仍未达成，作为实验功能提供。三阶候选解可以执行，只有“严格最短已确认”才表示最短性已证明。

通过 Git 获取源码时，先进入 `魔方拍照解` 目录，再按使用说明操作。照片在本机处理，服务只监听 `127.0.0.1`。
