# 任务收尾

清理本次任务生成的临时副本属于任务完成条件，不能以 `.gitignore` 已排除为由跳过。

1. 保存最终交付 ZIP、源码包或 wheel、校验信息，以及需要追溯的验收日志和 JSON。归档资料先确认已上传且哈希正确；清理验收解压目录前，将 acceptance.json 等独有记录移到保留目录。
2. 明确列出本次创建、验收成功后已不需要的构建/解压目录、重复下载和恢复验证副本。新任务将这些文件集中在 `artifacts/<task>/temporary/`，交付物与日志放在同级其他目录。
3. 删除前核对每个目标的绝对路径在项目工作区内，且不是工作区根目录、已跟踪文件、符号链接或 junction。仅清理本次任务拥有的路径，不使用笼统的全盘或全工作区删除。
4. 保留 `assets/`、原始 `initial/`、`.cache/htm`、`.cache/qtm`、活动原生程序、`.venv` 和 `node_modules` 等必要运行或可复用资源；现有发布交付物另行保留，除非用户要求清理。
5. 清理后验证保留的交付物和记录仍在，报告删除了什么、释放多少空间以及仍保留的大文件用途。清理失败或验收尚未完成时说明原因，不能宣称已完成收尾。
