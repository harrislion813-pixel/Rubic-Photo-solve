Cube Lens 1.10.0 · 魔方拍照求解

本便携包集成正式 HTM 和 QTM，适用 Windows 10/11 x64。
无需安装 Python、编译器或 Node.js，全部运行表和缓存已经生成。

1. 下载 .001、.002 与 QTM.cmd 到同一目录，双击 QTM.cmd 校验并合并。
2. 完整解压生成的 ZIP，进入 RubicPhotoSolve 文件夹。
3. 双击“启动魔方求解器.cmd”，保持启动窗口打开。
4. 浏览器未自动打开时，访问窗口打印的 http://127.0.0.1:端口/。
5. 选择二阶或三阶、HTM 或 QTM，上传 U R F D L B 六面并校正，开始求解。
6. 使用结束后在启动窗口按 Ctrl+C。

普通入口先交付 QTM 候选，后台完整校验强表后继续严格证明。
可选“启动QTM完整强表.cmd”：关闭旧服务后使用，先完成强表校验再搜索。
加载与校验计入请求超时；内存不足时可能采用较小配置。
QTM 完整强配置参考机工作集约 3.8 GiB，另需系统与浏览器内存。
下载、合并与解压建议预留 12 GiB 磁盘空间。

请保留 _internal、web、native、assets 和 .cache；更新时解压到新目录。
“校验安装.cmd”可验证全部资产散列；详细步骤见包内 README.md。
源码包只含基本代码，按 README 在本机生成运行表，无需下载便携包。
HTM 将 180° 计为 1 步，QTM 计为 2 步；90° 均计 1 步。
候选解可以执行，只有“严格最短已确认”才表示证明完成。
正式功能不承诺固定时间内证明任意状态，也不保证 QTM 比 HTM 快。
照片本机处理，服务仅监听 127.0.0.1。
