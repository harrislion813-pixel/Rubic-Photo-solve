魔方拍照最短解 - Windows 便携版
================================

使用方法
1. 完整解压 ZIP，不要直接在压缩包中运行。
2. 双击“启动魔方求解器.cmd”。
3. 浏览器会自动打开本地页面；如未打开，请使用窗口中显示的 http://127.0.0.1:端口/。
4. 录入六面并校正后，选择“180° 计步方式”，再点击“开始求解”。
5. 使用结束后，在运行窗口中按 Ctrl+C 停止服务。

说明
- 应用只监听本机 127.0.0.1，不会把照片上传到外部服务器。
- 包内已包含 Python 运行环境、OpenCV、前台快速求解表、C++ 求解器和严格最短证明所需的基础 PDB。
- 默认 HTM：R、R'、R2 各计 1 步；QTM：R 和 R' 计 1 步，R2 计 2 步。
- 二阶完整准确距离表随包提供：HTM 最大距离 11，QTM 最大距离 14。
- 切换计步方式会取消旧证明、清除旧解，照片和人工校正仍然保留；需要再次点击开始。
- 三阶默认预算 HTM 20 / QTM 26；候选可执行，但仅“严格最短已确认”表示证明完成。超时、取消或预算不足时仍未证明最短。
- 携带 QTM 标准资产的版本使用完整 QTM Corner/Phase-1 表与 Tail-7；强配置另含约 3.29 GiB 的联合表和 Tail-8，需要约 6 GiB 资产空间。
- 携带 QTM 资产的版本也包含 Python 回退使用的小表；原生程序不可用时仍按 QTM 代价搜索。
- 若缺少 QTM 专用资产，求解器可用 HTM PDB 作为合法下界；复杂状态的证明仍可能耗时较久。
- 完整解压并保留 web、native 和 .cache 目录；双模式协议、距离表和 PDB 已通过发布预检。
