魔方拍照最短解 - Windows 便携版
================================

使用方法
1. 完整解压 ZIP，不要直接在压缩包中运行。
2. 双击“启动魔方求解器.cmd”。
3. 浏览器会自动打开本地页面；如未打开，请使用窗口中显示的 http://127.0.0.1:端口/。
4. 使用结束后，在运行窗口中按 Ctrl+C 停止服务。

说明
- 应用只监听本机 127.0.0.1，不会把照片上传到外部服务器。
- HtmFull 包含 Python 运行环境、OpenCV、独立 HTM 求解器、完整主 PDB 和 Tail-6。
- QtmStrong 包额外包含按需启动的独立 QTM 实验引擎及强表；QTM 证明可能超时，候选解与严格最短证明分开显示。
- 首次二阶求解会在内存中生成二阶剪枝表，之后在本次运行中复用。
- asset-manifest.json 列出实际安装的引擎和资产 SHA-256。
